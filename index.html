Install on Android

Host this blank PWA package on an HTTPS site, then open it in Chrome and use ⋮ → Install app or Add to Home screen. Once installed, its icon is called Invest.

Privacy and limits

Do not upload a populated financial backup to a public website. Import private data only from this phone after the blank app has been installed. Local browser storage can be cleared by the OS or browser; export backups periodically.

No independent Robinhood authentication, Plaid API, Trading API, Seeking Alpha API, or ChatGPT private data feed is present in this standalone application. It does not perform trades or sync itself from ChatGPT.
